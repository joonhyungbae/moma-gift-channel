# MoMA named-donor gifts by record, work, and artist, 1929-2024

Replication code and data for *Counting women and non-Western artists in MoMA's named-donor gifts by record, work, and artist, 1929-2024* (Museum Management and Curatorship).

The paper reads MoMA's donor-identified gift records donor by donor and counts
each gift in three ways, as catalogue records, as works, and as distinct
artists. Shares of women and of non-Western artists differ between the counts, movements in
record shares come from a few gifts and depend on where the regional boundary
is drawn, and artists new to the collection arrive through donors of every
size. Every number, table and figure in the article and its supplement is
written by `code/56_rev_paper_assets.py`.

## Layout

```
code/        analysis pipeline (run_all.py) and shared helpers
data/        MoMA and Tate source data + the preprocessed analysis table
audit/       a reading of 300 credit lines used to check the credit-line parser (scripts 58 and 62)
output/      generated results (regenerated by the pipeline; not tracked)
```

## Reproduce

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r code/requirements.txt
python code/run_all.py
```

The raw MoMA snapshot (`data/Artworks_full.csv`) is included; the large derived
table `data/processed_moma_data.csv` is not tracked and is regenerated by the
first pipeline step. See `data/README.md` for data download instructions and
`code/REPLICATION.md` for the full data description and the script-to-paper map.
